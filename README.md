# meeting-ideas

This repository is used to curate and discuss potential topics for future GlosLUG meetups.

## How it works

- **Browse ideas** — check the [open issues](https://github.com/GlosLUG/meeting-ideas/issues) to see what topics are being considered
- **Suggest a topic** — [open a new issue](https://github.com/GlosLUG/meeting-ideas/issues/new) with your idea, whether it's something you'd like to see or something you'd be willing to present
- **Join the discussion** — comment on existing issues to show your interest or add thoughts

Ideas that get traction will be picked up and scheduled via the [Upcoming Talks project board](https://github.com/orgs/GlosLUG/projects/1).

Anyone is welcome to suggest topics — you don't need to be a member or commit to presenting. If you have an idea, throw it in!
